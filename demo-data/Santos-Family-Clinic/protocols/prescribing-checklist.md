# Santos Family Clinic — Prescribing checklist

1. Check the allergy line in the patient's intake and the latest visit note before any new prescription.
2. Check current medicines for interactions and duplicate drug classes.
3. For diabetic patients, check the latest kidney function result before changing metformin.
4. Record every medicine change (drug, dose, frequency, reason) in the visit note.
