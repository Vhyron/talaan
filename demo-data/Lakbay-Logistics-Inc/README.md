# Lakbay Logistics Inc. — HR investigations

This Space holds HR investigation files for Lakbay Logistics Inc. (Valenzuela warehouse and dispatch hubs). Each case folder is one employee investigation, opened and handled by HR Officer Bea Lim.

- **Type:** HR investigations (employee discipline under twin-notice due process)
- **Case folders:** one per case, named "Case <year>-<number> <employee surname>"
- **Company policies:** in `policies/`
- **Handling:** case files hold government ID numbers, health data and witness identities. Share only with the HR officer, the employee's representative (copies on written request) and the decision-maker.
- **Decision rule:** the HR officer flags facts and contradictions; only the decision-maker decides the outcome.
