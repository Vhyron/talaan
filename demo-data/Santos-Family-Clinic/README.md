# Santos Family Clinic — patient charts

This Space holds patient charts for Santos Family Clinic (general and internal medicine, Marikina). Each chart folder is one patient.

- **Type:** clinic patient charts (intake, SOAP visit notes, labs, referrals)
- **Chart folders:** one per patient, named "Chart <initial> <surname>"
- **Clinic protocols:** in `protocols/`
- **Handling:** charts hold PhilHealth and HMO numbers, diagnoses and family contacts. Share only with the treating doctor and, by written referral, a specialist.
