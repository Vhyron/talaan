# 07 · Rules and compliance

Summary of the AppBuildersPH participant briefing (Oct 9, 2026) as it affects us.

## Key rules

| Rule | Our compliance |
|---|---|
| Substantially built during the hackathon | Built from scratch; no fork of an existing app |
| A meaningful part of AI inference runs locally | **All** AI runs locally |
| Core Local AI works without depending entirely on a cloud AI API | No cloud AI at all |
| Cloud APIs allowed only as secondary components | We use none |
| Disclose models, APIs, frameworks, tools, existing code and assets | Full list in 06-demo-and-pitch.md |
| Open-source models and libraries allowed | Yes, all disclosed |
| AI-assisted development allowed | Yes, disclosed |
| No help from people outside the hackathon | Team members only |
| Disputes: pre-existing project, external help, fake benchmarks | Roadmap items clearly labelled as future; no invented numbers |
| One project per team, one submission, no edits | Check everything before submitting |
| Repo public by 10:00 AM; code freezes then | Push and verify public visibility before 9:30 AM |
| Finalists must be present at Demo Day | Someone from the team pitches on site |
